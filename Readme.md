# OSH FAQ

Dies ist eine Sammlung von typischen Fragen zu Open Source Hardware. Sie soll helfen ein Verständnis über verschiedene Themen, wie Lizenzierung, Haftung & Gewährleistung, Kombinierbarkeit oder technische Aspekte, wie Dateiformate und Software oder die Verwaltung der Quelldateien zu bekommen.

Die FAQ ist abrufbar unter: [https://iiottestbed.github.io/osh-faq/de/](https://iiottestbed.github.io/osh-faq/de/)
